# AutoPostTool

> Công cụ desktop hỗ trợ quản lý và tự động hóa các tác vụ Facebook.

---

## 📌 Giới thiệu

**AutoPostTool** là ứng dụng desktop được phát triển bằng Python, nhằm hỗ trợ quản lý tài khoản Facebook, Page, Group và các tác vụ đăng bài tự động.

Ứng dụng được thiết kế theo hướng **module hóa**, giúp giao diện, cấu hình và các chức năng xử lý được tách biệt, dễ phát triển và bảo trì.
